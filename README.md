# Focused

Первая тестовая версия YULO — основного трекер-проекта (репо для истории развития YULO). На iPhone и iPad можно вести сферы жизни, цели, задачи, привычки и заметки. Данные хранятся на устройстве.

При первом запуске приложение добавляет примеры, чтобы экраны были не пустыми.

## Возможности

**Vision**

- сферы жизни: название, цвет, иконка и удовлетворённость
- влияние целей, задач и привычек на сферу
- графики: радар, кольца, столбцы
- по желанию краткий разбор сферы через внешнюю модель. Без своего ключа эта часть молчит, остальные вкладки работают

**Цели**

- срок, награда, статус и архив
- подзадачи и счётчики
- фото или иконка, цвет, теги
- связь со сферой и отметка важных целей для сетки Vision

**Задачи**

- срок, повтор и статус
- подзадачи
- оценка времени и факт
- связь с целью и сферой

**Привычки**

- расписание и сколько раз отметить за день
- выполнено, пропущено, пропуск
- серии и архив
- цвет, иконка, теги и связь со сферой

**Заметки**

- альбом заметок, список, счётчик и серия
- настроение, навык, бюджет, время, здоровье и календарь
- теги и архив

**Общее**

- один календарь на все вкладки
- дашборд за неделю, месяц, квартал и год
- резервная копия в JSON: сферы, цели, задачи, привычки и заметки

## Требования

- Xcode 26
- iPhone или iPad с iOS 17.6 или новее
- свой ключ OpenRouter — только для разбора сфер. Остальное приложение от него не зависит

## Запуск

```bash
git clone https://github.com/dpogonia/Focused.git
cd Focused
open Focused.xcodeproj
```

Выберите симулятор iPhone и запустите схему **Focused**.

### Ключ для Vision

Ключ в репозиторий не входит. Задать его можно так:

- переменная окружения `VISION_ANALYTICS_API_KEY` в схеме: Product → Scheme → Edit Scheme → Run → Arguments → Environment
- или настройка таргета `INFOPLIST_KEY_VisionAnalyticsAPIKey`

По умолчанию запрос идёт на `https://openrouter.ai/api/v1/chat/completions`, модель `deepseek/deepseek-chat`. Адрес и модель меняются теми же настройками Info.plist: `VisionAnalyticsEndpointURL` и `VisionAnalyticsModelName`.
